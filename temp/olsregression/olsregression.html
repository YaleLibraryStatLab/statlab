Abstract

This research guide provides an introdcution to ordinary least square regression (OLS), including the theoretical and mathematical background of OLS, the assumptions of OLS, when to use OLS in practice, how to implement OLS regression, and how to interpret results from OLS regression.

Keywords

OLS, Regression, Continuous Varibales, Categorical Variables, R, Julia, glm, lm, t.test, anova

Introduction

Regression (Montgomery, Peck, and Vining 2021) is a powerful body of statistical methods for constructing equations to describe the relationship between a response variable (often referred to as a dependent or outcome variable) and a set of predictor variables (often referred to as independent variables). Regression models can be used for all three of the primary goals of statistical analysis:

  1. Description: to describe the relationship between response and predictor variables
  2. Inference: to infer relationships in a population based on relationships in a sample from that population
  3. Prediction: to predict future values of a response variable based on values of the predictor variables

Ordinary least squares (OLS) regression is the most common method for estimating a linear regression model. In this guide, we’ll discuss when to use OLS, the assumptions of OLS, how to implement OLS regression, and how to interpret results from OLS regression. Let’s start with a guiding example.

Performance in School

Educators, students, and parents are often quite invested in students’ performance on standardized tests. These test scores often play a large role in a student’s ability to be accepted into selective high schools and colleges.

The California Test Score Dataset contains data on test performance, school characteristics, and student demographic backgrounds for primary schools in California (Kleiber and Zeileis 2026). Using this dataset, we will assess how linear models (and specifically, ordinary least squares regression) can help us describe, infer from, and make predictions about test performance among these students.

Considering other Variables

Let’s plot the relationship between a school’s math score and a variable that we might believe is related: that school’s reading score. An initial hypothesis could be that schools with higher reading scores might have higher math scores (i.e, a hypothesis resting on the assumption that some schools are better or worse at both types of test). Another competing hypothesis could be that schools with higher reading scores might have lower math scores (i.e., a hypothesis resting on the assumption that some schools might be better at math, but this may be at the cost of a reading).

To get an initial sense on if either of these hypotheses are reasonable, we can plot a scatterplot of the math and read variables:

Based on this plot, it certainly looks like schools with higher reading scores also tend to have higher math scores. As such, when we reconsider the equal-means model from earlier, we can get already begin to easily think of ways to improve that model. Specifically, since we know that schools higher in one score tend to be higher in another, if we know a school is above the average in reading, we can predict that it is also likely to be above the average in math. Similarly, if we know a school is below the average in reading, we can predict that it is also likely to be below the average in math:

By looking at the plot above, we can see that most points fall in the lower-left corner and the upper right corner. That is, schools tend tend to be either above average in both reading and math, or below average in both reading and math. This suggests that we can make a better prediction about a school’s math score (and it’s relationship to the mean) if we also know that school’s reading score. Specifically, if we know a school is above average in reading, we can predict that it is also likely to be above average in math. Similarly, if we know a school is below average in reading, we can predict that it is also likely to be below average in math.

However, this is still a very simple model. What if we want to know the magnitude of how far a school’s math score is from the mean, based on how far that school’s reading score is from the mean? Better yet, what if we didn’t even have to directly consider the mean, and with just a school’s reading score, we could predict that school’s math score?

With OLS regression for one predictor variable, we can find the line of the form \(Y = \beta_0 + X\beta_1\) , where \(\beta_0\) and \(\beta_1\) are our regression coefficients that best fit the data. We can use this equation to make highly precise predictions about a school’s math score based on that school’s reading score.

Fitting the Line of Best Fit

There are an infinite number of lines that can be “fit” to a scatterplot of two variables.

How do we know what line best fits the data? Different methods differ in how they choose the “best” line for the data.

In OLS regression, this is done by minimizing the sum of squared residuals (SSR). A residual is the difference between the observed dependent variable, \(Y\), and the fitted or predicted values of the dependent variable, \(\hat{Y}\).

For OLS regression with one predictor, we obtain fitted values using the regression equation \(\hat{Y} = \hat{\beta}_0 + X\hat{\beta}_1\), where \(\hat{\beta}_0\) and \(\hat{\beta}_1\) are the estimated regression coefficients. So, in this setting, we want to find the values of \(\beta\) that minimize:

\[ \sum_{i=1}^n y_i - \beta_0 - X_i\beta_1 \]

For OLS regression with multiple predictors, we obtain fitted values using the regression equation \(\hat{Y} = \hat{\beta}_0 + X_1\hat{\beta}_1 + X_2\hat{\beta}_2 + ... + X_k\hat{\beta}_k\), where \(\hat{\beta}_0\) and \(\hat{\beta}_1\) are the estimated regression coefficients. So, in this setting, we want to find the values of \(\beta\) that minimize:

\[ \sum_{i=1}^n y_i - \beta_0 - X_{1i}\beta_1 - X_{2i}\beta_2 - ... - X_{ki}\beta_k \]

While most researchers use statistical software to estimate regression coefficients, we can also calculate the coefficients manually (so long as we are comfortable with some linear algebra). First we define X as the design matrix (in the case of one independent variable, the design matrix has two columns – the first is a column of 1s to represent the intercept, and the second is our X values). As such, predicted coefficients can be calculated using the following formula:

\[ \hat{\beta} = (\textbf{X}^T\textbf{X})^{-1}\textbf{X}^T\text{y} \]

Assumptions

For a model to give valid and meaningful results, certain assumptions are necessary. If any of these are violated, the results may not be valid.

1. Linearity

Linearity is the assumption that the relationship between the dependent and independent variable is linear.

Assessing and Addressing Violations

We can assess the linearity assumption by creating a scatter plot of the predictor and outcome variables. If there seems to be a a nonlinear relationship, the assumption is violated.

The two main ways to address a violation of linearity are:

  1. Transform the data - Applying a function to the variables, like a log function (e.g., \(\log(y)\)) or an exponential function (e.g., \(e^y\)), can often transform the data to make the relationship linear. However, interpretations of the now linear relationship should be cautious to use transformed scales.

  2. Fit a nonlinear model - An alternative regression model, like a GLM, might be better suited to fit a non-linear relationship than OLS regression.

2. Homoscedasticity of errors

Homoscedasticity of errors is the assumption that the error terms have equal variance across values of the predictor variable. As such, this assumption could be violated when the variance of the outcome variable changes across values of a predictor variable. For example, if we look to model someone’s income vs their expenditures, we might expect to find greater variability in how much money individuals with higher incomes spend vs individuals with lower incomes (i.e., variability in the outcome variable would increase with larger predictor variables). As such, the homescedasticity of errors assumption would likely be violated for this relationship.

Assessing and Addressing Violations

We can check this assumption by plotting the model residuals vs the predicted values. The points should look randomly scattered. If we see a pattern in the distribution of the residuals, the assumption is violated.

We can also check for homoscedasticity using a test such as the Breush-Pagan test (Hothorn et al. 2024a) or the White test (White’s Test 2019).

The two main ways to address a violation of homoscedastic errors are:

  1. Transform the data - Applying a transformation, like a log function (e.g., \(\log(y)\)) or a square root function (e.g., \(\sqrt y\)), can often make heteroscedastic errors more constant.

  2. Fit a weighted least squares regression model - Weighted least squares regression can better account for heteroscedasticity by minimizing a weighted sum of squared residuals.

  3. Use robust standard errors - Using robust (e.g., Huber-White) standard errors provides reliable estimates of the coefficient standard errors, even when the errors are heteroscedastic (Zeileis, Köll, and Graham 2020).

3. No autocorrelation of errors

No autocorrelations of errors is the assumption that errors of different observations are not correlated. This assumption is often violated in the case of time series data, where observations close in time may be highly correlated.

Assessing and Addressing Violations

We can check this assumption by plotting the residuals against any possible ordering variable (e.g., time). The points should look randomly scattered. If we see a pattern in the distribution of the residuals, the assumption is likely violated.

We can also check for autocorrelation using a test such as the Durban-Watson test (Hothorn et al. 2024b) or the Breusch-Godfrey test.

The main way to address a violation of no autocorrelation is to use an autoregressive model instead (Burant 2022).

4. Linear independence of the predictor variables

This assumption applies when there is more than one predictor variable (i.e., when fitting a multiple linear regression model). Linear independence of the predictor variables variables is the assumption that no predictor variable can be expressed as an exact linear combination of the others. This ensures that the variables contain unique information, and that the regression coefficients can be estimated without ambiguity. When this assumption is violated, it is referred to as multicollinearity.

Assessing and Addressing Violations

We can check this assumption by calculating a correlation matrix of all pairwise correlations between predictor variables. A value of 1 or -1 indicates perfect multicollinearity, while a value close to 1 indicates high multicollinearity.

We can also calculate the Variance Inflation Factor to determine how much the variance of a regression coefficient is increased due to multicollinearity (Thompson et al. 2017). A high VIF, such as VIF \(>5\), indicates high multicollinearity.

To simplest way to address multicollinearity is to remove one of the collinear variables from the model.

Implementation - Performance in School

Now we that we know what assumptions to test when fitting an OLS regression model, let’s use OLS regression with our school performance data from earlier. Specifically, let’s fit a model that predicts a school’s math score based on that school’s reading score. Since our predictor variable is a school’s reading score and our outcome variable is a school’s math score, we can write our model as a linear equation:

\[ \text{Math Score} = \beta_0 + \text{Reading Score}\times\beta_1 \]

where \(\beta_0\) is the intercept (i.e., the expected math score when reading score is 0) and \(\beta_1\) is the slope (i.e., the expected change in math score for a one unit increase in reading score). Note that in this case, the intercept is not meaningful since a reading score of 0 is not possible (in other examples, the intercept may be meaningful, such as when modeling someone’s income based on their years of higher education, where the intercept would represent the expected income for someone with 0 years of higher education). In our case, the slope is the more meaningful coefficient, as it represents the expected change in math score for a one unit increase in reading score.

Let’s fit this model using the lm function in R, interpret the results, and assess the assumptions to confrim that our interpretations are valid.

Fitting the Model using lm

From the output above, we can see that the estimated intercept is about 89.566, and the estimated slope is about 0.861. This means that for every one unit increase in reading score, we expect a 0.861 point increase in math score. Note that this equation allows us to describe the relationship between reading and math scores across schools, and to predict a school’s math score based on that school’s reading score (relating to the first and third goals of statistical analysis).

Linear model outputs from R also provide t-values and p-values for each coefficient. Generally, the t-value and p-value for the intercept are not of interest, since the intercept is often not meaningful. However, the t-value and p-value for the slope are of interest, since the slope is often the more meaningful coefficient.

The t-value is the estimated coefficient divided by its standard error, and the p-value is the probability of observing a t-value as extreme as the one observed, under the null hypothesis that the true coefficient is 0. This relates to the second goal of statistical analysis that regression can help with: inference. Specifically, we can use the t-value and p-value to test the null hypothesis that the true slope at the population-level is 0 (i.e., that there is no relationship between reading score and math score at the population-level). Note that the linear model associated with the null hypothesis is equivalent to the equal means model we considered earlier where the predicted math score is just the average math score across all schools and the slope is 0:

That the t-value for the slope is large and that the p-value is very small (p < .001) suggests that, at the population level, there is a significant relationship between reading score and math score. Additionally, since the estimated slope (and associated t-value), is positive, we can infer that the relationship between reading and math scores is also positive at the population-level. However, we should be cautious with what we consider the population in this case. Since all of the schools in this sample were primary schools in California, we can only be confident in our inference about the relationship between reading and math scores for primary schools in California. For example, we cannot be confident in our inference about the relationship between reading and math scores for high schools in California, or for primary schools across the United States.

Regardless, from the model above we can summarise our results with respect to the three goals of statistical analysis as follows:

  1. Description: There is a positive relationship between reading and math scores across primary schools in California, such that for every one unit increase in reading score, there is an expected 0.861 point increase in math score.

  2. Inference: This relationship does not seem to be due to random chance, and is likely to hold in the population of primary schools in California.

  3. Prediction: We can predict a school’s math score based on that school’s reading score using the equation \(\hat{Y} = 89.566 + 0.861X\).

These are powerful statistical interpretations that we can make from a simple linear regression model! However, we should be cautious in our interpretations if the assumptions of OLS regression are violated. Let’s check these assumptions to confirm that our interpretations are valid.

Assessing Linearity

From the scatterplots of math and reading scores above, the relationship between these two variables seems to be linear. As such, the linearity assumption seems to hold.

Assessing Homoscedasticity of Errors

To check the homoscedasticity of errors assumption, we can plot the residuals vs the fitted values from our model. The points should look randomly scattered. If we see a pattern in the distribution of the residuals, this assumption is likely violated:

# plot of residuals vs fitted values
CASchools %>%
  ggplot(aes(x = fitted(model_math_read), y = resid(model_math_read))) + 
  geom_point(alpha = 0.5) + 
  labs(title = "Residuals vs Fitted Values for OLS Regression Model of
Math vs Reading Scores",
       x = "Fitted Values", y = "Residuals") +
  theme_minimal()

From the plot above, there does not seem to be a clear pattern in the distribution of the residuals, suggesting that the homoscedasticity of errors assumption holds.

Assessing No Autocorrelation of Errors

To check the no autocorrelation of errors assumption, we can plot the residuals vs an ordering variable. The points should look randomly scattered. If we see a pattern in the distribution of the residuals, this assumption is likely violated:

# plot of residuals vs fitted values ordered by row
CASchools %>%
  ggplot(aes(x = 1:nrow(CASchools), y = resid(model_math_read))) + 
  geom_point(alpha = 0.5) + 
  labs(title = "Residuals vs Row Number for OLS Regression Model of
Math vs Reading Scores",
       x = "Row Number", y = "Residuals") +
  theme_minimal()

From the plot above, there does not seem to be a clear pattern in the distribution of the residuals across row number, suggesting that the no autocorrelation of errors assumption holds.

Assessing Linear Independence of the Predictor Variables

Since we only have one predictor variable in this model, the linear independence of the predictor variables assumption is not relevant here. However, if we had more than one predictor variable, we would need to check this assumption by calculating a correlation matrix of all pairwise correlations between predictor variables, and by calculating the Variance Inflation Factor for each predictor variable.

Interim Conclusion - Simple Linear Regression

Since the assumptions of OLS regression seem to hold, we can be confident in our interpretations of the model coefficients and associated t-values and p-values. Specifically, we can be confident that there is a significant positive relationship between reading and math scores across primary schools in California, such that for every one unit increase in reading score, there is an expected 0.86 point increase in math score.

With respect to our initial question about predicting the math score of a randomly selected school, we can now make a much more precise prediction. Specifically, if we know the reading score of the school, we can use the equation \(\hat{Y} = 89.57 + 0.86X\) to predict that school’s math score. For example, if we know a school has a reading score of 700, we can predict that school’s math score as follows:

\[ \hat{Y} = 89.566 + 0.861 \times 700 = 692.266 \]

Of course, this point lies on the fitted regression line, and we can see how this point relates to the rest of the data by plotting it on our scatterplot:

Considering Categorical Variables

So far, we have only considered how to use OLS regression to model the relationship between a continuous predictor variable (i.e., reading score) and a continuous outcome variable (i.e., math score). However, OLS regression can also be used to model the relationship between a categorical predictor variable and a continuous outcome variable. There are important and interesting parallels between OLS regression with categorical predictor variables and other linear models such as the t-test (when there are only 2 levels to the predictor variable) and ANOVA (when there are more than 2 levels to the predictor variable).

In our California schools dataset, we have a categorical variable called grades which indicates if the primary school is from Kindergarden to 6th grade, or from Kindergarden to 8th grade. We can use OLS regression to model the relationship between this categorical variable and the math score variable. But first, let’s look at some summary statistics and plots from the two levels of this categorical variable to get a sense of the relationship between this variable and math scores.

Given the large t-value and small p-value, we can infer that there is a significant difference in math scores between K-6 and K-8 schools at the population level. Specifically, since the mean math score for K-6 schools is higher than the mean math score for K-8 schools, we can infer that K-6 schools have higher math scores than K-8 schools at the population level.

As expected, the means for each group from the output from t.test match the means we calculated manually above. The t-statistic from above can also be recovered from the means and standard deviations of the two groups using the following formula:

\[ t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} \]

Calculated as such:

t_recovered <- (
  mean(CASchools$math[CASchools$grades == "KK-06"]) -
    mean(CASchools$math[CASchools$grades == "KK-08"])
) /
  sqrt(
    sd(CASchools$math[CASchools$grades == "KK-06"])^2 /
      length(CASchools$math[CASchools$grades == "KK-06"]) +
      sd(CASchools$math[CASchools$grades == "KK-08"])^2 /
      length(CASchools$math[CASchools$grades == "KK-08"])
  )

There are a few key things to note from the above output. First, the estimated intercept is about 652.028, which is exactly the mean math score for the reference group (i.e., K-8 schools). Second, the estimated slope is 9.047, and this is exactly the difference in means between K-6 and K-8 schools that we calculated manually above and that we also got from the t-test output. That is, the estimated slope represents the expected change in math score for K-6 schools compared to K-8 schools, which is simply the difference in means between the two groups.

Like with the OLS regression model we fit earlier with the continuous variables, we obtain a t-value and p-value for the coefficients in this model that we can use for inference to the population level. The t-value for the slope is large and the p-value is very small (p < .001), which suggests that there is a significant difference in math scores between K-6 and K-8 schools at the population level. This can also be interpreted in terms of the slope of the line that connects the means between the two groups: since the p-value for the slope is very small, we can infer that the slope of the line connecting the means between K-6 and K-8 schools is significantly different from 0 at the population level. Since the slope is positive, we can also infer that K-6 schools have higher math scores than K-8 schools at the population level.

Importantly, the t-value and p-value for the slope in this regression model is not the exact same as the t-value and p-value from the t-test output, despite them both being tests on if the difference-in-means (i.e., slope) is different from zero. This is because the t-test output uses a different formula to calculate the standard error of the difference in means than the formula used to calculate the standard error of the slope in the regression model. Specifically, the t-test output uses the formula for the standard error of the difference in means that does not assume equal variances between the two groups, while the regression model uses the formula for the standard error of the slope that does assume equal variances between the two groups.

To get the exact same t-value and p-value as the OLS regression model, we can specify in the t.test formula that the variances of the two groups are equal,, so it will then use the same formula for the standard error as the OLS regression model:

# t-test for difference in math scores between K-6 and K-8 schools with equal variances
t.test(math ~ grades, data = CASchools, var.equal = TRUE)
